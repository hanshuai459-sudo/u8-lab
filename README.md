## 使用

打开首页，进入实验。搜索仅筛选当前实验资料；整表复制只包含筛选后已核对的行，带表头，列间使用制表符、行间使用换行符。不要将多列内容直接粘贴到U8单个字段。

单字段复制优先调用 IE 的 clipboardData，其次尝试 execCommand；失败时显示选中文本框，手动按 Ctrl+C。也可以点击只读字段后直接 Ctrl+C。所有编号、金额、税号与账号均为字符串。教材留空字段保留空字符串，不补成0。

进度只保存于当前浏览器，学校电脑与个人电脑不自动同步。离开机房前下载进度JSON文件，或复制进度文本，使用自己的邮箱/网盘转移。另一台电脑打开网站后导入。导入会覆盖文件中相同实验编号的记录，其他实验保留；请先导出本地备份。

本地存储被禁用时会提示，当前页面关闭或刷新前请导出。IE8等不支持文件读取/下载的浏览器，可用进度文本转移。禁止把账号密码或真实个人隐私写入进度备注。

## 兼容范围

设计目标为 IE8 标准模式及以上，JavaScript 使用 ES5 及早期兼容写法，事件支持 attachEvent，无 fetch、Promise、ES模块、React、Vue、CSS Grid、Flexbox 或外部字体。IE8没有媒体查询，使用电脑双栏布局；支持媒体查询的手机浏览器使用单栏。

14个页面是独立静态HTML；禁用JavaScript仍可浏览全部目录、表格和步骤，手动选择文字复制。搜索和进度需要JavaScript。当前环境没有学校机房的真实IE，不能把现代浏览器测试当作IE实测。旧Windows的TLS、根证书或学校网络可能影响GitHub Pages的HTTPS连通性，需机房实测，不降低安全设置。

## 本地运行与后续补充

直接打开 index.html 可阅读；推荐在此目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

在浏览器打开 http://127.0.0.1:8765/ 。

`data/labs.json` 是教材内容的唯一维护入口。修改后执行：

```powershell
python tools/build.py
```

生成首页与 labs/ 下的13个页面。生成器仅使用Python标准库，机房访问无需安装Python。不要直接修改生成HTML，以免下次构建丢失内容。补充资料时保留其他实验数据、既有id和已核对记录；先比对原始照片再修改待核对项。所有字段必须是JSON字符串，不允许把001写成数字1。

表格结构：id（全站唯一英文id）、title、source（页码表号）、columns（表头数组）、rows（行数组）。每行包含values（字符串数组）、source、verified（布尔）。verified为false时整行不开放按钮复制，整表也排除该行。留空用空字符串；无法辨认写“待核对”，verified设为false。

步骤结构：title、source、menu、button、fields、save、check，均为字符串。教材没有提供的部分填“待核对”，不得推测。新增表格和步骤应能追溯页码。
