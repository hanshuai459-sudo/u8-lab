期初余额试算不平衡，将不能记账，但可以填制凭证。已经记过账，则不能再输入、修改期初余额，也不能执行“结转上年余额”功能。（照片3，试算平衡注意事项）

操作步骤指导

1. 登录总账子系统

来源：实验三照片2，操作指导第1项（页码未完整拍入）

  1. 进入菜单：开始 → 程序 → 用友U8 V10.1 → 企业应用平台。也可双击教材所示桌面图标，打开“登录”对话框。
  2. 点击按钮：在登录对话框完成教材要求的登录，单击“确定”；然后在“业务工作”选项卡中单击“财务会计”→“总账”。
  3. 填写数据：操作日期：2024-01-01。公开版省略教材操作员、密码及登录账套信息；实验要求身份为账套主管“陈明”。
  4. 保存：登录信息填写后单击“确定”（教材原步骤；未另述保存动作）。
  5. 检查结果：进入“业务工作”，单击“财务会计”→“总账”后展开“总账”下级菜单。

2. 设置总账控制参数

来源：实验三照片2，操作指导第2项；参数来源照片1表4-2

  1. 进入菜单：在总账管理系统中执行“设置”→“选项”，打开“选项”对话框。
  2. 点击按钮：单击“编辑”进入选项编辑状态；分别打开“凭证”“权限”“其他”选项卡。
  3. 填写数据：按表4-2设置：可以使用应收受控科目；可以使用应付受控科目；出纳凭证必须经由出纳签字；部门、个人、项目按编码排序。
  4. 保存：设置完成后，单击“确定”。
  5. 检查结果：教材未单独提供保存后的检查方法，待核对。

3. 输入无辅助核算科目的期初余额

来源：实验三照片3，操作指导第3项第1小项；金额来源照片1表4-3

  1. 进入菜单：执行“总账”→“设置”→“期初余额”，进入“期初余额录入”窗口。
  2. 点击按钮：教材此处直接在科目期初余额栏输入，未指定额外按钮；输入后按Enter键确认。
  3. 填写数据：先输入“1001库存现金”的期初余额8700，再输入实验资料中其他无辅助核算科目的期初余额。仅在最末级明细科目上输入；上级科目自动计算并填列，合计数不需输入。
  4. 保存：教材明确输入后按Enter键确认；未另述保存按钮，待核对。
  5. 检查结果：教材说明上级科目自动计算并填列；输入全部余额后按下方“试算平衡”操作检查。

4. 输入辅助核算科目的期初余额

来源：实验三照片3，操作指导第3项第2小项；明细来源照片2表4-4

  1. 进入菜单：执行“总账”→“设置”→“期初余额”，进入“期初余额录入”窗口。
  2. 点击按钮：双击“应收账款”的期初余额栏，进入“期初往来明细”窗口；单击“增加”，再单击“往来明细”。
  3. 填写数据：先输入表4-4中应收账款的明细核算信息，再输入其他辅助核算科目的期初余额。教材说明其他应收款、应付账款的输入方式与应收账款类似。
  4. 保存：输入明细核算信息后单击“汇总”，退出；教材未另述保存按钮，待核对。
  5. 检查结果：完成所有科目余额录入后，按下一项“试算平衡”检查。

5. 试算平衡

来源：实验三照片3，操作指导第3项第3小项

  1. 进入菜单：在完成所有科目余额输入后的“期初余额录入”窗口操作。
  2. 点击按钮：单击“试算”，打开“期初试算平衡表”对话框。
  3. 填写数据：教材此处未要求填写新数据；若期初余额不平衡，则修改期初余额直到平衡为止。
  4. 保存：单击“确定”（教材原步骤；未另述保存动作）。
  5. 检查结果：检查期初试算是否平衡。教材提醒：不平衡不能记账，但可以填制凭证；已经记过账不能再输入或修改期初余额，也不能执行“结转上年余额”。
